# Telas arquivadas (escopo "Vitrine")

Estas telas faziam parte do fluxo transacional de vagas/match/candidatura, removido
na mudança de escopo para o modelo de **Vitrine / Catálogo** de talentos e empresas.

Arquivadas em: 02/09/2026

## Motivo
A plataforma deixou de ter vagas internas, match e candidatura. O contato entre
empresa e talento passa a acontecer por canais externos (portais de vagas da empresa,
links de portfólio do aluno).

## Arquivos
| Arquivo | O que era |
|---|---|
| `painel-vagas.html` | CRUD de vagas da empresa (Minhas Vagas) |
| `painel-vaga-cadastro.html` | Criação de vaga (empresa) |
| `painel-vaga-editar.html` | Edição de vaga (empresa) |
| `painel-vaga-candidatos.html` | Candidatos de uma vaga (empresa) |
| `aluno-painel.html` | Feed de vagas disponíveis (aluno) |
| `admin-vagas.html` | Moderação de vagas (admin) |
| `admin-vaga-cadastro.html` | Criação de vaga (admin) |
| `admin-vaga-candidatos.html` | Candidatos de vaga (admin) |

> Mantidas apenas para referência histórica. Não estão linkadas na navegação ativa.
